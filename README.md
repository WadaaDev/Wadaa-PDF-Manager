# Wadaa PDF Manager

**A powerful all-in-one tool for merging and managing documents in PDF format.**

Wadaa PDF Manager is a Windows desktop application that makes it easy to combine different document types into a single PDF file. Merge PDFs, PowerPoint presentations, Excel spreadsheets, and images with flexible page selection, PDF preview, and document splitting — all through a simple and intuitive interface.

## Features

- **Multi-Format Merging:** Combine PDF files, PowerPoint presentations, Excel spreadsheets, and images into one PDF document.
- **Flexible PDF Page Selection:** Choose specific pages or page ranges from PDF files before merging.
- **PDF Splitting:** Extract selected pages or sections from PDF documents during the merging workflow.
- **PDF Preview:** Preview PDF documents before adding them to the final output.
- **Last Session Recovery:** Restore your previous working session and continue where you left off.
- **Automatic Updates:** Keep the application up to date with the latest releases.
- **Simple Desktop Interface:** Easy-to-use interface designed for efficient document management.
